## 🛠️ Tecnologias
* HTML5
* CSS3 (Tema escuro/claro em tons de azul e lilás)

* **Super Trunfo em C:** Jogo de cartas interativo no terminal (`C`).
* **43 Exercícios em Python:** Desafios de lógica e algoritmos resolvidos (`Python`).
